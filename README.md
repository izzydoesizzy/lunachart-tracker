# LunaChart Tracker

> Track lunar cycles, moon phases, and align your personal rhythms with the cosmos.

[![GitHub Pages](https://img.shields.io/badge/demo-live-brightgreen)](https://izzydoesizzy.github.io/lunachart-tracker/)

---

## What Is This?

A beautiful, open-source moon phase tracker and personal rhythm journal. View current and upcoming lunar phases, log how you feel across the cycle, and discover patterns between moon phases and your energy, mood, and productivity.

### Planned Features

- **Live moon phase display** — current phase with visual representation
- **Monthly lunar calendar** — full month view with all phases marked
- **Personal journal** — log mood, energy, sleep, and notes by day
- **Pattern insights** — correlate your entries with lunar phases over time
- **Notifications** — alerts for full moons, new moons, and eclipses
- **Beautiful dark UI** — designed for nighttime viewing

## Tech Stack

- HTML, CSS, JavaScript
- GitHub Pages

## Getting Started

```bash
# Clone the repo
git clone https://github.com/izzydoesizzy/lunachart-tracker.git
cd lunachart-tracker

# Open in browser
open index.html
```
